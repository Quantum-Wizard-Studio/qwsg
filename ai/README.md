# AI Collaboration Workspace

## Purpose

This area holds the authoritative coordination, governance, project, prompt, backup, and chronological history records for Quantum Wizard Server Guardian.

## Status

Initial governance baseline for version `0.0.1-prealpha`.

## Scope

Stable rules belong in `core/`, project context in `projects/`, reusable instructions in `prompts/`, rollback evidence in `backups/`, and delivery reports in `history/`. Application code, credentials, runtime logs, and generated secrets do not belong here.

These records will evolve during development through reviewed, chronological updates.

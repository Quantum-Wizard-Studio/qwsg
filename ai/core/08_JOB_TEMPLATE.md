# Engineering Job Template

## Purpose

This template defines the minimum safe record for a future Quantum Wizard Server Guardian task.

## Status

Ready for use; it does not authorize implementation by itself.

## Template

- Objective and exclusions
- Verified starting state
- Snapshot location
- Planned smallest safe change
- Rollback procedure
- Implementation record
- Verification evidence
- Documentation updates
- Unresolved issues and delivery result

Task facts and evidence belong in completed job records. Secrets, assumptions presented as facts, and unrelated work do not. This template will evolve during development based on reviewed experience.

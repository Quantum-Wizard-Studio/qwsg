# Release Policy

## Purpose

This policy defines how versions of Quantum Wizard Server Guardian will be prepared, verified, documented, and recoverably released.

## Status

Pre-alpha baseline; `0.0.1-prealpha` is a foundation version, not a functional release.

Version criteria, checks, changelog requirements, artifacts, approvals, and rollback notes belong here. Unverified binaries, secrets, undocumented dependencies, and unsupported release claims do not. This policy will evolve before any public release.

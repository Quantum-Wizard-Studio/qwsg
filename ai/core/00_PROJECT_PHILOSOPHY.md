# Project Philosophy

## Purpose

This document defines the enduring design philosophy of Quantum Wizard Server Guardian (QWSG).

## Status

Mandatory initial philosophy for `0.0.1-prealpha`.

## Principles

- QWSG exists to protect Linux servers, not merely observe them.
- It behaves like a careful and experienced system administrator.
- It observes, verifies, analyzes, explains, and warns.
- It performs automatic corrective action only when explicitly authorized.
- Stability has priority over convenience; security has priority over shortcuts.
- Every relevant change must be logged, and every operation must be understandable.
- Every destructive action must be reversible where technically possible.
- The system must remain modular and installable on independent Linux servers.
- QWSG must not depend on QUWIP or any other Quantum Wizard product.
- The web interface must be an independent QWSG console.
- The project must remain maintainable years after its creation.
- The Guardian never assumes when it can verify.
- The Guardian never hides changes.

## Scope

Durable values and decision principles belong here. Task instructions, transient implementation details, credentials, and product-specific dependencies do not. This philosophy will evolve during development only through deliberate, documented approval.

# Quantum Wizard Server Guardian Project Record

## Purpose

This document is the concise project-level context for QWSG contributors.

## Status

Version `0.0.1-prealpha`; governance, product and architecture baselines plus an internal Core Alpha Slice 1 implementation. No supported product release exists.

QWSG is an independent, modular Linux server guardian with a standalone Agent, privileged lifecycle Installer, and optional independent Console. The parent product record is `docs/PRODUCT_DEFINITION.md`; high-level direction is `docs/PRODUCT_SYSTEM_BLUEPRINT.md`; observable Core Alpha behavior is `docs/FUNCTIONAL_SPECIFICATION.md`; and technical design begins at `docs/architecture/CORE_ALPHA_ARCHITECTURE.md`. Slice 1 is limited to non-root read-only discovery and inventory. Open architecture and release gates remain controlling. The master plan is preserved non-normative source material. Approved scope, constraints, milestones, and cross-document pointers belong here.

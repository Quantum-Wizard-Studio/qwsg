# Quantum Wizard Server Guardian Project Record

## Purpose

This document is the concise project-level context for QWSG contributors.

## Status

Version `0.0.1-prealpha`; governance and directory foundation plus an owner-review Product Definition. Product Architecture and implementation have not started.

QWSG is an independent, modular Linux server guardian with its own console. The consolidated product-level definition is `docs/PRODUCT_DEFINITION.md`; its established constraints restate approved governance, while labeled strategic proposals require owner approval. Approved scope, constraints, milestones, and cross-document pointers belong here. Secrets, host-specific credentials, unverified assumptions, and dependencies on other Quantum Wizard products do not. This project record will evolve during development.
